# Me Like Cats
A Simple Website To Relax

> **Sometimes the world moves a little too fast, and we just need a quiet place to step back, catch our breath, and disconnect. And That's Okay!** <br>
> Just Enjoy The Music And Of course The Cats!


### Technical
This Website Runs On HTML With The [Cataas](https://cataas.com/) API (It Really Is My Favorite API :] )
And In The Background It Plays Some Of The Songs From Volume Alpha By C418 (Which You Can Find [Here](https://archive.org/details/2011-c418-minecraft-volume-alpha))

Not A Lot About It But I Hope Y'all Can Enjoy The Music And The Cats :)
